# Aviator Signal Bot (Educational Demo)

> **Important disclaimer**  
> This project is for educational purposes only.  
> Aviator uses provably fair cryptography. Crash points are unpredictable.  
> No bot, signal service, or strategy can give a long-term edge.  
> Do not use this (or any similar tool) with real money.

## What it does
- Loads historical crash multipliers from a CSV
- Computes basic statistics and streak information
- Generates purely heuristic “signals” based on past data
- Runs a simple flat-bet backtester
